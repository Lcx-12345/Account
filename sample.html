文件格式支持说明

本页面展示了支持和不支持的文件格式列表，以及相关示例代码。

支持的文件格式

  • .html ✓ 支持
  • .md ✓ 支持
  • .py ✓ 支持
  • .json ✓ 支持
  • .svg ✓ 支持
  • .js ✓ 支持
  • .css ✓ 支持
  • .txt ✓ 支持

不支持的文件格式

  • .zip ✗ 不支持
  • .rar ✗ 不支持
  • .7z ✗ 不支持
  • .ppt ✗ 不支持
  • .pdf ✗ 不支持
  • .jpg ✗ 不支持
  • .png ✗ 不支持
  • .mp4 ✗ 不支持

HTML 代码示例

<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<title>示例页面</title>
</head>
<body>
<h1>Hello World</h1>
</body>
</html>
注意：对于不支持的二进制文件格式（如 .zip、.ppt、.pdf 等），需要使用专门的工具或应用程序来处理。
