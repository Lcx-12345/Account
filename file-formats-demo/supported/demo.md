# Markdown 文件示例

## 简介

这是一个 Markdown 格式的示例文档，展示了 Markdown 的各种常用语法。

## 常用语法

### 文本格式化

- **粗体文本**：使用 `**文本**` 或 `__文本__`
- *斜体文本*：使用 `*文本*` 或 `_文本_`
- ~~删除线~~：使用 `~~文本~~`
- `行内代码`：使用反引号包裹

### 列表

无序列表：
- 项目一
- 项目二
  - 子项目 A
  - 子项目 B

有序列表：
1. 第一步
2. 第二步
3. 第三步

### 代码块

```python
def hello_world():
    print("Hello, Markdown!")
    return True
```

### 表格

| 名称 | 类型 | 描述 |
|------|------|------|
| id | int | 唯一标识符 |
| name | string | 名称 |
| created_at | datetime | 创建时间 |
