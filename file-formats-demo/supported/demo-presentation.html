文件格式介绍
各种常见文件格式的特点与应用

本演示文稿将介绍多种文件格式的特性和用途。

1 / 6
文档格式

Markdown (.md)

轻量级标记语言，易于阅读和编写，广泛用于文档写作。

HTML (.html)

超文本标记语言，用于创建网页和Web应用。

2 / 6
代码格式
  • Python (.py) - 简洁优雅的编程语言，应用广泛
  • JavaScript (.js) - Web前端开发的核心语言
  • TypeScript (.ts) - JavaScript的超集，添加了类型系统
  • Go (.go) - Google开发的高性能编程语言
  • Rust (.rs) - 注重安全和性能的系统编程语言
3 / 6
数据格式

JSON (.json)

JavaScript对象表示法，轻量级数据交换格式。

{ "key": "value" }

YAML (.yaml)

人类可读的数据序列化格式，常用于配置文件。

4 / 6
图像格式
格式 类型 特点
SVG 矢量图 可缩放、文件小、基于XML
PNG 位图 无损压缩、支持透明
JPEG 位图 有损压缩、适合照片
5 / 6
总结
  • 选择合适的文件格式可以提高工作效率
  • 文本格式易于版本控制和协作
  • 二进制格式通常文件更小、读取更快
  • 不同场景应选择不同的文件格式
