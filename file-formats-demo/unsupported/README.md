# 不支持直接生成的文件格式

以下是一些无法直接生成的二进制文件格式，以及相应的替代方案。

## 压缩文件格式

### ZIP (.zip)
- **描述**: 最常见的压缩文件格式
- **原因**: 二进制格式，需要特殊的压缩算法
- **替代方案**: 
  - 使用命令行工具创建：`zip archive.zip files/`
  - 使用 Python 的 zipfile 模块创建

### RAR (.rar)
- **描述**: 另一种流行的压缩格式
- **原因**: 专有格式，专利限制
- **替代方案**: 使用 ZIP 或 7z 格式

### 7Z (.7z)
- **描述**: 7-Zip 压缩格式
- **原因**: 二进制格式
- **替代方案**: 使用命令行工具 `7z`

## 办公文档格式

### PowerPoint (.ppt, .pptx)
- **描述**: Microsoft PowerPoint 演示文稿
- **原因**: 复杂的二进制/OOXML 格式
- **替代方案**:
  - 使用 HTML 格式的演示文稿（参见 supported/demo-presentation.html）
  - 使用 Markdown + Marp/Slidev 等工具生成
  - 使用 Python 的 python-pptx 库生成

### Word (.doc, .docx)
- **描述**: Microsoft Word 文档
- **原因**: 复杂的二进制/OOXML 格式
- **替代方案**:
  - 使用 Markdown 格式
  - 使用 HTML 格式
  - 使用 Python 的 python-docx 库生成

### Excel (.xls, .xlsx)
- **描述**: Microsoft Excel 电子表格
- **原因**: 复杂的二进制/OOXML 格式
- **替代方案**:
  - 使用 CSV 格式（纯文本）
  - 使用 HTML 表格
  - 使用 Python 的 openpyxl 或 pandas 库生成

### PDF (.pdf)
- **描述**: 便携式文档格式
- **原因**: 复杂的二进制格式
- **替代方案**:
  - 使用 HTML 格式
  - 使用 Markdown 然后用工具转换（如 pandoc）
  - 使用 Python 的 reportlab 或 fpdf 库生成

## 图像格式

### PNG (.png)
- **描述**: 便携式网络图形
- **原因**: 二进制位图格式
- **替代方案**:
  - 使用 SVG 矢量图格式（参见 supported/demo.svg）
  - 使用专门的图像生成工具

### JPEG (.jpg, .jpeg)
- **描述**: 联合图像专家组格式
- **原因**: 二进制位图格式，有损压缩
- **替代方案**:
  - 使用 SVG 矢量图格式
  - 使用专门的图像生成工具

### GIF (.gif)
- **描述**: 图形交换格式
- **原因**: 二进制位图格式
- **替代方案**:
  - 使用 CSS 动画
  - 使用 SVG 动画

## 音视频格式

### MP3 (.mp3)
- **描述**: MPEG 音频层 III
- **原因**: 二进制音频格式
- **替代方案**: 不适用，需要专门的音频处理工具

### MP4 (.mp4)
- **描述**: MPEG-4 视频
- **原因**: 二进制视频格式
- **替代方案**: 不适用，需要专门的视频处理工具

## 数据库文件

### SQLite (.db, .sqlite)
- **描述**: SQLite 数据库文件
- **原因**: 二进制数据库格式
- **替代方案**:
  - 使用 SQL 脚本（.sql 文件）
  - 使用 CSV/JSON 等数据格式

## 可执行文件

### 二进制可执行文件 (.exe, .bin, 等)
- **描述**: 编译后的可执行程序
- **原因**: 平台相关的二进制格式
- **替代方案**: 提供源代码，用户自行编译

## 总结

虽然无法直接生成上述二进制文件格式，但可以：
1. 使用纯文本格式作为替代（Markdown、HTML、CSV、JSON 等）
2. 使用脚本生成二进制文件（Python 库等）
3. 使用专门的工具进行格式转换

所有支持直接生成的文件格式示例，请查看 `supported/` 目录。
